# HB Motos - Site Premium

## Melhorias Implementadas

### Design Premium
- **Animações avançadas**: Scroll reveal, pulse glow, fade effects
- **Gradientes e sombras**: Efeitos de profundidade modernos
- **Hover effects**: Transformações suaves nas cards e imagens
- **Glassmorphism**: Bordas e efeitos de brilho

### Estrutura do Site
```
HB-Motos-site/
├── index.html              # Página principal premium
├── assets/
│   ├── css/
│   │   └── style.css       # Estilos premium com animações
│   ├── js/
│   │   └── main.js         # Scripts de animação e interatividade
│   └── images/
│       ├── p3-jpeg          # Fotos da oficina
│       ├── p4.jpeg          # Equipamentos
│       ├── p5.jpeg          # Mecânicos em ação
│       ├── p6.jpeg          # Área de serviços
│       ├── p7.jpeg          # Peças e acessórios
│       ├── p8.jpeg          # Clientes atendidos
│       ├── Propaganda1.jpeg # Promoções
│       └── prpaganda2.jpeg  # Novidades
```

### Seções Principais
1. **Hero Section**: Logo animada com efeito de pulsação
2. **Serviços**: Cards interativos com lista animada
3. **Horário de Funcionamento**: Card destacado
4. **Contato**: Informações com links ativos
5. **Galeria de Oficina**: 6 imagens com hover effects
6. **Promoções**: Cards com propaganda

### Tecnologias Utilizadas
- CSS3 com variáveis customizadas
- Flexbox e Grid Layout
- Intersection Observer API
- Animações CSS (keyframes)
- Transições suaves cubic-bezier

### Responsividade
- Layout adaptativo para mobile (max-width: 768px)
- Cards que se re Organizam em coluna única em telas menores
- Imagens redimensionam-se adequadamente

## Como visualizar
Acesse o arquivo `index.html` em qualquer navegador moderno para ver o site premium.
